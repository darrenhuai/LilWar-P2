# LilWar-P2

A collection of early JavaScript exercises: small console and browser games and utilities, built while learning JS fundamentals.

## What's here

- **PigGame/** and `PigGame.js` / `app.js` - the dice game Pig, both a console version (Node, using `readline-sync`) and a browser GUI version.
- **Blackjack/** - a browser-based Blackjack game with card graphics.
- **players_turn/** - a small turn-tracking browser app.
- `matrix_cipher_cli.js` - a command-line matrix cipher encoder/decoder.
- `hi_world.html`, `allstar.txt`, `code.txt` - misc early exercises.

## Running the console Pig game

```
npm install readline-sync chalk
node app.js
```

## Running the browser projects

Open the relevant `index.html` (or `pig_game.html`, `cardlook.html`) directly in a browser.
